# SimpleRTS (Godot)

Минимальный прототип RTS в стиле Warcraft на Godot 4.

## Управление
- ЛКМ: выбрать юнита или здание.
- ПКМ: отдать приказ на движение выбранным юнитам.
- B: нанять юнита из выбранного здания.

## Содержимое
- `scenes/Main.tscn` — главная сцена с HUD.
- `scenes/Unit.tscn` — юнит с выбором и перемещением.
- `scenes/Building.tscn` — здание, из которого можно нанимать юнитов.
- `scenes/Resource.tscn` — ресурсный узел для визуального окружения.
